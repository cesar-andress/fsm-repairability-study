# Citation and archival policy

## Recommended citation

When you cite this software-and-data artifact in a paper, report, or replication package, use the **Zenodo DOI** for the archived release, not an informal GitHub URL alone.

**Andrés, C. (2026).** *fsm-repairability-study: Reproducible Protocol and Frozen Pilots for Behavioural FSM Repair Evaluation* (Version 2.0.0 — IST Artifact Freeze) [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.20517969

Machine-readable metadata: [`CITATION.cff`](../CITATION.cff) at the repository root (CFF 1.2.0).

## GitHub `main` vs Zenodo archived releases

| | GitHub (`main` branch) | Zenodo archived release |
|--|------------------------|-------------------------|
| **Purpose** | Ongoing development, documentation fixes, metadata updates | Long-term preservation and **citable** snapshot |
| **Mutability** | May change after publication | **Immutable** for a given Zenodo version |
| **What to cite** | Use only if you explicitly need the latest commit; prefer Zenodo for reproducibility claims | **Preferred** for papers and replication audits |

The Zenodo deposit [10.5281/zenodo.20517969](https://doi.org/10.5281/zenodo.20517969) is the **IST artifact freeze (v2.0.0)**, including infrastructure and three frozen pilot campaigns under `freezes/`.

The earlier record [10.5281/zenodo.20529518](https://doi.org/10.5281/zenodo.20529518) (v1.0.x) covered **infrastructure only** and is superseded for empirical claims in the IST manuscript.

## Scientific claims and archived releases

- **Protocol and infrastructure claims** should reference the **v2.0.0** Zenodo DOI you verified.
- **Empirical claims** in the IST manuscript (executability counters, outcome classes, failure taxonomies) are supported by the **frozen pilot bundles** in that same v2.0.0 deposit and by Tier~A regeneration scripts included in the archive.
- Do not attribute unpublished results or private experiments to the public Zenodo record.
